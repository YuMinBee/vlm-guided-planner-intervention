# 좌표 수정 이후의 경로·속도·제어 검증

2026년 9월 10일 개발 실험의 집계다. 기존 졸작에서 확인했던 실패 상황
보완 결과와 구분하며, 새 학습 연결층의 성능으로 해석하지 않는다.

## 좌표 입력 수정과 제어 개선의 구분

로컬 구현에서 프롬프트는 차량 기준이라고 설명하면서 변환 전 목표점을
전달하는 오류가 확인됐다. 관측 당시 차량 위치·방향으로 변환하고
x=전방/y=우측으로 전달하도록 수정했다. 좌표 수정만 적용한 구성에서도
문제 경로의 충돌은 남았다. 따라서 이후 개선을 좌표 수정 하나의 효과로
설명하지 않는다.

## 후속 구성

1. **회전 완료 확인:** 명령 관측 당시의 경로 출구를 기억하고 차량의
   방향·위치가 출구와 정렬됐는지 확인한다. 내비게이션 명령이 차로 유지로
   바뀌었다는 이유만으로 회전을 끝내지 않으며 정지 명령은 우선한다.
2. **경로·속도 공동 선택:** 실제 조향에 쓸 공간 경로와 속도 후보를 함께
   검사하고, 필요한 회전 경로도 추가한다. 후보 배열 번호를 좌/우회전 의미로
   간주하지 않는다. 원래 후보 점수와 예측 장애물·경로 기하를 함께 사용한다.
3. **검사와 실행의 일치:** 후보의 차량 운동 예측과 실제 조향에 같은
   pure-pursuit 계산을 사용한다. 기존 종방향 PID는 유지한다.

기존 특화 7B VLM과 HiP-AD 가중치는 동결했다. VLM이 조향·가속 값을
직접 생성하거나, 공유 레이어·학습 연결층이 이 결과를 만든 것은 아니다.

## 문제 경로 비교

경로27532의 비교 기준도 좌표 수정이 적용된 구성이다.

| 구성 | 시드 | 구조물 충돌 | 차량 충돌 | 완료율 | Driving Score | 게임 시간 |
|---|---:|---:|---:|---:|---:|---:|
| 좌표 수정 기존 구성 | 0 | 1 | 1 | 100% | 39.0 | 21.85초 |
| 기존 구성 + 조향기만 교체 | 0 | 1 | 1 | 100% | 39.0 | 21.00초 |
| 후속 연결·제어 구성 | 0 | 0 | 0 | 100% | 100.0 | 21.95초 |
| 후속 연결·제어 구성 | 1 | 0 | 0 | 100% | 100.0 | 22.15초 |

같은 고정 제어 구성으로 기존 성공 경로2989와3482도 각각24.55초와19.35초에
충돌 없이 완주했다. 확인 범위는 선정3개 경로의4회 완주이며 전체 데이터셋의
성공률은 아니다. 회전 기억 제거 비교는 실제 시간 한도로 종료되어 정식 교착
실패나 정상 완주로 집계하지 않았다. 모든 개별 모듈의 효과가 분리 입증된 것은 아니다.

## 연결 검증과 한계

- 저장된88개 프레임에서 고정 선택기의 후보·속도·경로 선택이 실행 기록과
  일치했다. 네 성공 실행의 제어 기록178개에서도 선택 결과의 제어 입력 전달을
  확인했다. 이는 새 실제 주행을 대신하지 않는다.
- 9월11일 로컬 통합 패키징 후에는 기존/신규 테스트23개, 저장 선택88프레임,
  실제 decoder 메서드의 최종 경로·속도 출력5프레임을 검사했다. 이 통합
  코드는 본 저장소의 공개 범위에 포함하지 않았고, 패키징 후 재주행은 하지 않았다.
- 첫 성공 실행에서 VLM 추론 중앙값은 실제 시간0.87초, 응답 수신 시 정보
  나이는 시뮬레이션 시간0.10초였다. 계산 중 시뮬레이션이 멈추므로 이 두
  값을 혼동하거나 실제20Hz 동작·지연 강인성으로 해석하면 안 된다.
- 운동 예측은 타이어 슬립·조향 지연을 생략하고 탐지·예측된 장애물에
  의존한다. 모든 충돌 방지나 실제 도로 안전성을 보장하지 않는다.
- 별도로 시험한 학습 연결층·학습 후보 선택기는 검증 개선을 확인하지 못했으며
  위 표의 구성에 포함하지 않는다.

## 저장소 반영 범위

공개 코드는 [관측 시점 좌표 변환](capture-coordinates.md)과 기존 비동기
참조 런타임이다. 위 후속 제어는 로컬 통합의 방법·집계 검증 기록으로 공개한다.
HiP-AD 통합 패치, 모델, 영상, 원본 프레임 기록은 올리지 않는다. 이 저장소를
설치하는 것만으로 표의 제어 구성이 자동 적용되는 것은 아니다.
