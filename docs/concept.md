# 계획 개입의 동작 설계

## 역할과 구현 범위

VLM은 카메라와 경로 문맥에서 고수준 의도를 제공한다. 계획기는 연속 경로·속도
후보를 만들고, 실행 계층은 의도의 유효성·경로 기하·예측 장애물·제어 가능성을
함께 확인한다. VLM이 조향·가속 수치를 직접 생성하지 않는다.

공개 `src/vlm_async_gate/`는 관측 좌표 변환과 비동기 결과의 시간 계약을
구현한다. 아래 회전 상태·공동 선택·제어 계산은 로컬 통합의 설계이며 공개
참조 코드가 이 전체 기능을 구현한다는 뜻은 아니다.

## 관측과 좌표 계약

카메라, 차량 위치·방향, 경로 목표점은 같은 시점의 관측으로 묶는다.
목표점의 세계 좌표에서 차량 위치를 뺀 변위를 전방·우측 단위축에 투영한다.
VLM 입력의 x는 전방, y는 우측이며, 프레임 ID와 시뮬레이션 시각을 보존한다.
모든 입력은 같은 세계 좌표계와 거리 단위를 사용해야 한다.

`capture_navigation`은 명시된 두 축으로 투영하고 불변 좌표 튜플을 반환한다.
어느 시뮬레이터의 compass 값이 그 축에 대응하는지는 통합 계층의 책임이다.
응답 수신 시점의 새 위치로 원본 관측 좌표를 덮어쓰지 않는다.

## 비동기 의도 수용

크기1 큐에서 아직 처리하지 않은 최신 관측만 유지한다. worker가 반환한 명령은
원본 프레임·시뮬레이션 시각에 연결하며, 만료되거나 유효하지 않은 결과는
새 개입으로 사용하지 않는다. 참조 런타임의 신뢰도 값은 호출자가 제공하는
값이며 모델이 보정된 확률을 자동으로 출력한다는 가정은 하지 않는다.

의도 예시는 `lane_follow`, `straight`, `left`, `right`, `stop`,
`change_lane_left`, `change_lane_right`다. 계획기는 응답 대기와 독립적으로
계속 계산한다. 유효한 개입이 없으면 통합 계층의 기본 경로 정책을 사용한다.

## 회전 의도의 실행 상태

로컬 통합에서는 회전 명령의 관측 시점 경로가 같은 방향을 뒷받침할 때만
회전 상태를 시작한다. 당시 출구의 세계 위치를 기억하고 현재 차량 위치·방향을
대조해 진행과 완료를 판단한다. 다음 경로 명령이 차로 유지로 바뀌었다는
이유만으로 진행 중인 회전을 종료하지 않는다.

늦은 관측이나 이미 완료한 명령이 다시 회전을 시작하지 않게 관리한다.
진행 중에도 정지 명령이 우선하며 현재 장면의 충돌 검사는 계속한다.
회전 기억의 상태 전이와 VLM 결과 자체의 TTL은 서로 다른 조건이다.

## 경로·속도 공동 선택

기존 계획기의 공간 경로와 속도 후보를 조합해 실행 후보를 만든다.
경로 출구를 따르는 추가 후보도 만들 수 있다. 각 조합을 현재 속도에서
운동 예측하고 예측 장애물과의 겹침·경로 기하·원래 후보 점수를 함께 고려한다.

```text
candidate = (spatial_path, desired_speed)
feasible = predicted motion is compatible with path coverage and obstacle checks
selection = highest supported utility among feasible candidates
```

로컬 구성은 필요할 때 목표 속도를 낮춰 가능한 조합을 찾으며, 적합한 조합이
없으면 정지 폴백을 사용한다. 정지는 실제 감속 거리를 고려해야 하므로 원하는
속도를0으로 설정했다는 이유만으로 즉시 정지한 것으로 계산하지 않는다.

후보 배열의 번호나 이름만으로 좌/우회전 의미를 부여하지 않는다. 명령별 고정
인덱스 마스크·목표점 이동·제한 보정은 초기 통합에서 사용한 별도 방식이며,
현재 공동 선택 구성의 필수 단계로 중첩하지 않는다.

## 검사한 계획과 제어의 일치

충돌 검사에 쓴 경로와 실제 조향에 전달하는 경로, 목표 속도와 실제 종방향
제어 입력이 일치해야 한다. 로컬 구성은 후보 운동 예측과 실제 조향에 같은
pure-pursuit 계산을 사용하고 기존 속도 PID를 유지한다.

같은 계산을 사용해도 타이어 슬립·조향 지연·탐지 누락을 제거하지는 못한다.
예측상 적합한 후보가 실제 도로에서 안전하다는 보장은 없다.

## 평가와 해석

평가는 좌표 계약, 명령 수용, 후보 선택, 제어 입력 전달, 실제 주행을 구분한다.
완료율과 함께 충돌·경로 이탈·정지·주행 시간, 후보 선택 재현, 개입 정보 나이와
실제 추론 시간을 기록한다. 같은 시드·모델·경로 조건의 비교가 필요하다.

[제어 검증 기록](grounded-control-validation.md)은 선정 경로의 로컬 결과다.
그 결과를 공개 런타임의 모의 테스트, 학습 연결층의 효과 또는 전체 데이터셋
성능으로 확대하지 않는다. 추가 지연을 준 실제 실행과 넓은 경로 평가는 별도다.
