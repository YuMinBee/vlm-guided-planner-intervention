# 개념 설계

## 1. 목적

VLM의 장면 이해 능력을 기존 멀티모달 궤적 계획기와 결합하되, VLM이 연속 제어를 직접 담당하지 않도록 역할을 제한한다. 결합 지점은 계획기의 **최종 후보 선택 단계**다.

이 접근은 다음 실패 형태를 대상으로 한다.

- 경로 의도와 반대되는 후보가 전체 최고 점수를 얻는 경우
- 명령 벡터나 목표점이 입력되었지만 최종 모드 선택에는 충분히 반영되지 않는 경우
- 명목상 같은 명령 그룹에 속한 후보 중 일부가 실제로는 다른 방향의 형태를 갖는 경우

## 2. 구성 요소

### 장면 의미 추론

VLM은 카메라 관측과 필요한 최소 문맥을 받아 고수준 명령, 신뢰도, 선택적 근거 태그를 출력한다. 출력 형식은 자유 문장보다 제한된 스키마가 적합하다.

예시 명령 집합:

```text
LANE_FOLLOW, TURN_LEFT, TURN_RIGHT,
CHANGE_LANE_LEFT, CHANGE_LANE_RIGHT, UNKNOWN
```

### 기존 궤적 계획기

기존 계획기는 장면 표현으로부터 `n`개의 후보 궤적과 각 후보의 점수를 출력한다.

```text
planner(x) -> {(τ_i, s_i)} for i = 1..n
```

### 명령별 후보 정책

정책 `A(c)`는 명령 `c`가 주어졌을 때 경쟁에 참여할 수 있는 후보 인덱스 집합을 반환한다. 이 집합은 계획기의 내부 모드 구조를 분석해 오프라인에서 정하고 버전으로 고정한다.

중요한 점은 모드 이름이나 인덱스 순서만으로 의미를 단정하지 않는 것이다. 각 후보의 실제 형상을 측정하고, 필요하면 다음 특징으로 정책을 보정한다.

- 일정 시간 후 횡방향 변위의 부호와 크기
- 종방향 진행량
- 초기·최종 방위각 변화
- 곡률과 곡률 변화율
- 차선 중심선 또는 경로 기준선과의 관계

### 의미 마스킹과 기하 검증

개념적인 보정 점수는 다음처럼 표현할 수 있다.

```text
adjusted_score(i) = s_i - semantic_mask(i, c) - λ * geometry_penalty(τ_i, c)
```

`semantic_mask`는 후보가 `A(c)` 밖에 있으면 충분히 큰 벌점을 준다. `geometry_penalty`는 명령과 궤적 형상의 불일치를 연속적인 값으로 반영한다. 최종 선택은 허용 후보에 대해서만 수행한다.

```text
i* = argmax adjusted_score(i), where i is in A(c)
```

## 3. 폴백 원칙

VLM은 오인식과 지연이 있을 수 있으므로 폴백을 설계의 일부로 둔다.

- VLM 신뢰도가 임계값보다 낮으면 VLM 제약을 사용하지 않는다.
- 허용 집합에 유효한 후보가 없으면 기존 계획기의 선택이나 별도 안전 궤적으로 전환한다.
- 연속 프레임의 명령이 급격히 바뀌면 히스테리시스 또는 최소 유지 시간을 적용한다.
- 교차로 회전 명령은 경로 플래너가 같은 회전을 지시할 때까지 적용하지 않는다.
- 경로 기반 명령과 VLM 명령이 충돌하면 원래 경로 명령과 목표점을 유지한다.
- VLM 응답이 제어 주기보다 느리면 마지막 유효 명령을 제한된 시간 동안만 재사용한다.

### 목표점의 책임 분리

VLM은 연속 좌표를 직접 생성하지 않고 고수준 명령만 제공한다. 평상시 목표점은
경로 플래너가 제공한다. 회전 명령과 경로 명령이 일치한 경우에만 지도에서 해당
방향의 주행 가능한 후속 분기를 찾고, 검증된 로컬 좌표를 조건 입력으로 사용한다.
유효한 지도 분기가 없거나 좌표 검증에 실패하면 명령과 목표점을 함께 원래 경로로
되돌린다.

## 4. 왜 목표점 보정만으로 부족할 수 있는가

목표점이나 명령 임베딩은 후보 생성 분포를 움직이는 간접 조건이다. 하지만 최종 선택기가 모든 후보의 원래 점수를 그대로 비교한다면 의미적으로 다른 후보가 여전히 승리할 수 있다.

후보 집합 제한은 최종 의사결정 공간 자체에 제약을 건다. 따라서 입력 보정과 경쟁 관계가 아니라, 입력 보정을 보완하는 별도 안전·일관성 계층으로 볼 수 있다.

## 5. 보정 절차

1. 고정된 검증 장면 집합에서 모든 후보 궤적을 저장한다.
2. 각 모드의 형상 통계와 주행 의미를 분석한다.
3. 명령별 초기 허용 집합을 만든다.
4. 잘못된 방향, 정지, 과도한 곡률 후보를 제외하는 기하 규칙을 정의한다.
5. 정책과 기반 모델 체크섬을 함께 버전 관리한다.
6. 기반 모델이 바뀌면 모드 의미가 달라질 수 있으므로 다시 보정한다.

이 과정은 평가 데이터의 정답을 온라인에서 참조하지 않는다. 테스트 구간에 맞춘 수동 인덱스 선택을 피하고, 별도의 보정·검증·테스트 분할을 유지해야 한다.

## 6. 평가 계획

비교군:

- 기존 계획기
- 목표점 또는 명령 입력만 보정
- 명령별 그룹 마스킹
- 그룹 마스킹 + 기하 검증
- 전체 제안 방식 + 신뢰도 폴백

권장 지표:

- 명령과 선택 궤적의 의미 일치율
- 경로 완주율 및 이탈률
- 충돌, 적신호, 차선 침범 등 안전 지표
- 횡가속도, 저크, 곡률 변화 등 승차감 지표
- 폴백 발동률과 잘못된 제약 비율
- VLM 지연 및 전체 제어 루프 지연

## 7. 주장하지 않는 것

- 이 문서는 신규성이나 특허 가능성을 주장하지 않는다.
- 특정 기반 모델에서의 성능 향상을 보장하지 않는다.
- VLM 판단을 안전 인증된 신호로 간주하지 않는다.
- 실제 차량 배포에 필요한 안전 검증을 대체하지 않는다.
