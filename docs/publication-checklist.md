# 공개 전 체크리스트

이 문서는 법률 자문이 아니라 공개 범위를 점검하기 위한 실무 목록이다.

## 권리와 공개 시점

- [ ] 학교, 회사, 연구비, 공동연구 계약에서 결과물의 소유권 조항을 확인했다.
- [ ] 공동 기여자가 있다면 공개와 저자 표기에 동의받았다.
- [ ] 특허 출원을 고려한다면 공개 저장소 전환 전에 담당자 또는 전문가와 상의했다.
- [ ] 비밀유지계약이나 비공개 프로젝트 정보를 드러내지 않는다.

## 제3자 자료

- [ ] HiP-AD 및 다른 프로젝트의 코드, 설정, 패치, 그림, 표를 넣지 않았다.
- [ ] 모델 가중치, 데이터셋 샘플, CARLA 녹화물과 생성 로그를 넣지 않았다.
- [ ] 논문이나 저장소는 링크와 서지 정보로만 인용했다.
- [ ] 향후 제3자 코드를 추가할 때는 해당 라이선스와 NOTICE 의무를 별도로 검토한다.

## 표현과 연구 주장

- [ ] 실험하지 않은 결과를 성능 개선 사실처럼 표현하지 않는다.
- [ ] 비교 수치에는 재현 가능한 평가 조건과 출처를 붙인다.
- [ ] `최초`, `유일`, `특허 가능` 같은 표현은 선행기술 조사 없이 사용하지 않는다.
- [ ] 실제 차량용 안전성을 입증한 것으로 오해될 문구를 피한다.

## 저장소 설정

- [ ] 첫 업로드는 비공개 저장소로 한다.
- [ ] 비밀값, 개인 경로, 사용자 이름, 서버 주소가 Git 기록에 없는지 검사한다.
- [ ] 공개 전 커밋 전체와 대용량 파일 목록을 다시 검사한다.
- [ ] 라이선스를 부여할지, 권리를 유보할지 명시적으로 결정한다.

## 권장 공개 순서

1. 비공개 저장소에서 문구와 기여자 범위를 검토한다.
2. 필요하면 발명 신고 또는 특허 상담을 먼저 진행한다.
3. 제3자 자료가 없음을 다시 확인한다.
4. 공개가 적절하다고 판단한 뒤 저장소 가시성을 변경한다.
