# 문 열림 시나리오 영상

두 파일은 동일한 Town13 `VehicleOpensDoorTwoWays` 경로의 로컬 실험을
1980×540, 20 fps H.264 MP4로 압축한 기록이다. 원본 캡처와 실행 로그는 이
저장소에 포함하지 않는다.

| 파일 | 결과 | 프레임 | 설명 |
|---|---|---:|---|
| `open-door-success.mp4` | 완주 | 376 | VLM의 `change_lane_left`가 60프레임 동안 인접 차선 target과 제한된 waypoint 보정에 반영됨. 충돌·차선 이탈 0, 경로/페널티/종합 100/1.0/100 |
| `open-door-failure.mp4` | 진단 중단 | 522 | VLM은 열린 문과 좌측 변경을 인식했지만 수정 전 통합 설정에서 정체됨. 진행률 31.99%에서 수동 중단, 충돌 0 |

실패 영상은 VLM이 문을 인식하지 못한 사례가 아니다. 두 영상은 기반 계획기와
VLM의 성능을 통계적으로 비교하는 대조 실험도 아니며, 통합 설정 수정 전후의
동작 차이를 보여 주는 단일 진단 사례다.

영상에 보이는 CARLA 고유 에셋은 CARLA 프로젝트가 밝힌 CC-BY 조건을 따르며,
배경 계획기 HiP-AD는 Apache License 2.0으로 배포된다. 저작권·출처와 비제휴
표시는 [제3자 자료 문서](../../THIRD_PARTY.md)를 따른다.
